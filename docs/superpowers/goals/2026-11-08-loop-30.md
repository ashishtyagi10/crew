# Loop — ten UI, ten smith and ten crew rounds, one release

**Status: IN PROGRESS.** Set by the user on 2026-11-08: *"run the UI, AI(Smith) and Crew
loop 10 iteration of each. Only release when all 30 iterations are completed, one of the UI
enhancement iteration should include a new 3D theme for crew."*

## Rules that hold every round

The rules of the [loop before it](2026-11-04-loop-39.md) carry over, with one change: **no
round releases.** Each round is one commit on the `loop/l30` branch in the main checkout,
gated before it is committed (`cargo fmt --all --check`, `cargo check --workspace
--all-targets` with no warnings, and the tests of every crate it touched). A test fails
without each fix; every `.rs` file stays under the 200-line cap. The lanes take turns (UI,
smith, crew, then again). After round 30 the branch is merged `--no-ff` into `main` as one
release, with one CHANGELOG entry listing all thirty, and the Release, Windows and Coverage
runs are read after.

One UI round ships a new 3D theme, built on the v0.30.5 `Stage3dPass` backdrop.

## The survey (once, for all thirty rounds)

Three at once, one per lane, each starting from the last loop's closing list: what is still
real in the code, plus what is new. Each lane keeps a ranked queue of at least ten.

## Log

**Round U1: prism, a 3D theme — jade glass with its own scene of drifting prisms.**

- **The survey** found crew with a 3D backdrop (v0.30.5, `/look 3d orbit`) but no 3D theme:
  the scene was off unless set by hand, every theme drew the same one, and `Stage3dPass`
  hard-matched `Stage::Orbit`, rebuilt only on a palette change, and dropped threers'
  renderer when the stage went off, so a theme that turned a scene on would rebuild every
  pipeline (seconds in release, ~30 s in debug) each time `auto` walked into it.
- **Now** `prism` is a ninth theme (`RandomMode::Prism`, one page, `presets_prism.rs`): a
  jade page (4, 30, 26), ice-mint accent, coral activity, teal→violet ring, a dark-room
  glass like neon's (window 0.75, slab 0.45), own ANSI hues, syntax map and SF Mono lead;
  it passes the duplicate, pool, walk, signal, liquid, syntax and font gates. Its scene
  comes from `ThemeId::scene()`: `backdrop_3d` empty now means "the theme's", `off` is
  kept (`look3d::resolve`), so nobody else's window changed. `stage3dprism.rs` draws nine
  faceted prisms and two gems at three depths, placed by frustum fraction, in a page-colour
  fog, with a halo. `Stage3dPass` rebuilds on a stage change and keeps the renderer when
  off. Tests: `prism_tests` (3), `stage3dprism_tests` (wrap, in frame at aspects 0.6–3.0,
  three depths, fog), `prism_fills_the_frame_and_the_renderer_outlives_off` (fails with the
  renderer dropped on off: built twice), `look3d_tests` (fails with `""` → none), plus the
  updated cycle/walk/pool/picker/report tests. Shots: `stage3d_shot_prism_theme`,
  `glass_window_shot` (prism-window), `stage3d-prism`.
