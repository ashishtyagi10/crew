# Loop — ten UI, ten smith and ten crew rounds, one release

**Status: IN PROGRESS.** Set by the user on 2026-11-08: *"run the UI, AI(Smith) and Crew
loop 10 iteration of each. Only release when all 30 iterations are completed, one of the UI
enhancement iteration should include a new 3D theme for crew."*

## Rules that hold every round

The rules of the [loop before it](2026-11-04-loop-39.md) carry over, with one change: **no
round releases.** Each round is one commit on the `loop/l30` branch in the main checkout,
gated before it is committed (`cargo fmt --all --check`, `cargo check --workspace
--all-targets` with no warnings, and the tests of every crate it touched). A test fails
without each fix; every `.rs` file stays under the 200-line cap. The lanes take turns (UI,
smith, crew, then again). After round 30 the branch is merged `--no-ff` into `main` as one
release, with one CHANGELOG entry listing all thirty, and the Release, Windows and Coverage
runs are read after.

One UI round ships a new 3D theme, built on the v0.30.5 `Stage3dPass` backdrop.

## The survey (once, for all thirty rounds)

Three at once, one per lane, each starting from the last loop's closing list: what is still
real in the code, plus what is new. Each lane keeps a ranked queue of at least ten.
