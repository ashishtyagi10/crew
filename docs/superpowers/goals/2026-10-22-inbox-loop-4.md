# Loop — the inbox, a fourth five rounds

**Status: IN PROGRESS.** Set by the user after the third loop closed
(`2026-10-21-inbox-loop-3.md`): *"run the inbox enhancement loop 5 more times"*.

## Rules that hold every round

As in the second and third loops, which the user set:

- No feature the user did not ask for. A round fixes, simplifies or polishes what is there.
- `r` replies to everyone on the mail; there is no other reply, and no Bcc.
- The list, the open mail and the reply box are each a card, and the mail's card is always
  taller than the reply box.
- Every surface is judged on both pages; every file stays under the 200-line cap; the foot
  keeps every key visible; nothing is fetched that was not fetched before; no scratch file
  stays in the tree while `scripts/release.sh` runs.

## One round

1. **Survey** a path the earlier loops did not walk: its code, text dumps of the pane, shots.
2. **Pick** the fixes a reader would notice most, none of them a new feature.
3. **Build** them with tests, look again, release, and log the round below.

## Log

**Round 1 (v0.27.68): agent smith's draft and the box it was asked for.**

- **The survey** (the code of Tab in the reply box, from the ask to smith's settled answer).
  Since `r` opens the box, Tab there is the only way to ask smith for a draft, but the pending
  draft did not know that: if the box closed before smith answered (let go with Esc, or your
  own reply sent), the late draft was saved into Gmail as a draft in the thread, behind your
  back. And a second Tab while smith wrote asked again, for a second draft.
- **A draft for a closed box is let go** (`crates/crew-app/src/inbox/handoff.rs`), with a line
  saying so; the Gmail-draft path it fell into (`Ask::Draft`, `Got::Drafted`, `Gmail::draft`)
  had no other way in and is gone.
- **Tab asks once**: while smith writes, a second says `agent smith is still writing the
  draft…`.
- **Tests:** a draft for a closed box asks nothing of Gmail, through the app's own collection
  of smith's answer too; a second Tab does not ask again.
